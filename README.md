# ☕ Espresso – The Dessert Bar

**Espresso – The Dessert Bar** is an interactive dessert café website designed to showcase a variety of desserts, beverages, pastries, and café offerings through an attractive and user-friendly interface.

This project demonstrates fundamental front-end web development concepts using **HTML, CSS, and JavaScript**.

## ✨ Features

* Attractive and user-friendly interface
* Interactive website functionality using JavaScript
* Dessert and beverage menu showcase
* Visually appealing product presentation
* Easy navigation between different sections
* Organized and responsive layout
* Multiple dessert and beverage categories
* Simple and engaging café-themed design

## 🛠️ Technologies Used

* **HTML5** – Used to structure the website and organize its content.
* **CSS3** – Used for styling, layouts, colors, and the overall visual appearance.
* **JavaScript** – Used to add interactivity and dynamic functionality to the website.

## 🚀 How to Run the Project

1. Clone or download the repository.
2. Open the project folder.
3. Open `index.html` in any modern web browser.
4. Explore the website and its interactive features.

No additional installation or dependencies are required.
